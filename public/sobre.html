SOBRE O PROJETO

Como funciona o Estuda+.

O Estuda+ é um projeto acadêmico para organizar atividades de estudo por matéria, prazo e prioridade.

Cadastre uma tarefa

Abra Minhas tarefas. Preencha o título, a matéria, o prazo e a prioridade de cada atividade.

Edite e filtre

Edite quando seus planos mudarem. Encontre atividades pela busca ou filtre pelo status.

Acompanhe o progresso

Concluiu uma atividade? Marque como concluída e acompanhe a evolução na barra de progresso.

Dúvidas frequentes

Preciso criar uma conta?

Não. Você pode começar a organizar suas tarefas assim que abrir o site.

Onde minhas tarefas ficam salvas?

Elas ficam em um banco SQLite no computador que está rodando o servidor PHP. O planejamento continua salvo quando você fecha o navegador. O botão Exportar .txt permite guardar uma cópia para leitura.

Posso alterar uma tarefa depois de cadastrá-la?

Sim. Use Editar para mudar os dados, Concluir para finalizar ou Reabrir para voltar a estudar. A exclusão pede uma confirmação antes de remover a tarefa.

O site funciona no celular?

Sim. O layout se adapta ao tamanho da tela, e o menu fica disponível pelo botão Menu.
